# M153-Indizes

Course materials for **module M153** on database **indexes**. This repository collects the
documents so anyone can understand the topic.

## Contents

- `M153-Indizes.docx` — the write-up covering database indexes (what they are, how they work,
  and when to use them).

## Usage

Open `M153-Indizes.docx` in Microsoft Word, LibreOffice, or any compatible reader.

> Note: the material is written in German.
